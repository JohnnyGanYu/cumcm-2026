# 问题三优化报告：200 秒目标

交付版本：`q3-fast-v2`。对照是本次修改前的 `q3-fast-v1` 精确快照；问题四保持 `q4-fast-v3`。

独立随机源数 100 局中，合计平均定位清除时间由 **241.24 秒** 降至 **237.47 秒**，变化 **1.56%**（正值表示提速）；各局均值由 **245.86 秒** 变为 **241.85 秒**。

**200 秒目标尚未达到。** 本次未连接官方模拟器，不能把离线结果当作新版官方成绩，也不能保证每一局达到目标。

连同固定 10/13/16 源各 20 局压力测试，共完成 **160 局配对**；新版清除 **2045/2045** 个源，清除数退化 **0 局**。

## 修改与依据

1. 首次在原自适应覆盖和半径1150米的六站环之间，按已知目标的混合巡回长度及检测成本选择方案；选择后保留该模式，六站环在12个旋转角中挑选较短路径。
2. 六站环使用连续覆盖证明消除格心外包造成的残余搜索。只有同一未知频道实际在原点及六站全部沉默，才停止该频道搜索；缺测、别的频道测过、仅计划访问均不能作为判空依据。最坏接收距离988.5114米，距1000米下界有11.4886米余量。
3. 清除位置保持19.9米的全定位区域覆盖保证，同时考虑下一段路程：在两个安全端点间选择两段路程和更短的落点。
4. 每次检测前重查16个不同源频道的公开上界，防止同站扫频列表过期后仍检测未知频道；已有线索但未清除的频道继续补测与重试。
5. 保留150米直接清除阈值、250米搭载补测基线、所有定位兜底和预算。单条示向度激进逼近、提前清除和改变搭载阈值等试验未获稳定收益，未纳入。

策略只使用公开规则和每频道实际接口观测，不读取测试种子、真实位置、接收半径或实际总源数；计时和物理模型未修改。共享清除几何函数、Q4、基础策略和可行域模块保留原实现。

## 对截图与局限的说明

- 截图三局合计评分 209.01 秒，逐局均值 215.90 秒。11 源慢局原点只发现 2 源，另两局分别发现 12/8 源；慢局无失败清除、无尾部空搜。主要额外开销来自搜索和移动。
- 本地随机分布、观测误差场与官方案例不同，不能直接把截图的 209.01 秒与新版离线数字相减，也不能按离线降幅预测官方已达标。
- 调参和独立验证分开，最终源数随机种子为 262009001–262009100；固定 10/13/16 源分别为 262009201–220、262009301–320、262009401–420。种子提前查重并保存计划；全部计划案例、慢局和错误均留存。
- 每局离线客户端提供固定 1200 秒剩余预算，使虚拟时间比较不被本机负载改变；真实官方墙钟预算还需正式复测。
- 262 项回归通过，结果见 `results/q3_200_regression_final.txt`；另有独立的 Q4 行为一致性和发行包检查。
