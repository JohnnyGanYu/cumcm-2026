# 问题一：交会定位区域的直径算法与外接圆覆盖判定

> 对应设计文档 §3.1、§4.2 与需求 R1.1–R1.8、正确性性质 P1/P2/P3。所有几何算法与常量均以
> 仓库实现 `src/b_sim/geometry.py`（`localization_region` / `localization_polygon` /
> `polygon_diameter` / `circle_on_diameter_covers`）为根据；反例数值由
> `src/b_q1_counterexample.py`（`mpmath` 60 位高精度）复核，配图由 `src/b_q1_figures.py` 生成。

## 1.1 问题重述

测向机在**静止**状态下对某频道检测，返回带 ±1° 误差的**示向度** `svd_deg`（正东为 0°、逆时
针为正）。若在若干检测点 `p_i = (x_i, y_i)` 分别测得示向度 `θ_i`，则每次观测把干扰源约束在
一个以 `p_i` 为顶点、张角 `2ε = 2°`（`ε = 1°` 为误差绝对上界）的**楔形** `W_i` 内。所有观测
楔形之交即为**定位区域** `P`。问题一要求：

1. **直径算法**：给出由多个检测点及其示向度确定定位区域，并计算该区域**直径** `D`（区域内
   任意两点的最大距离）的算法；
2. **外接圆覆盖判定**：以区域直径为直径（圆心取直径中点 `M`、半径 `D/2`）作圆，判断该圆是否
   **总能覆盖整个定位区域**，并给出结论与依据。

本文的结论是：**以区域直径为直径的圆不一定能覆盖整个定位区域**。存在明确的反例族（正三角形
型区域），且平面上的最紧上界由 Jung 定理给出 `r* ≤ D/√3`。下文给出算法、判据、反例与证明。

## 1.2 交会定位的几何模型

**楔形（半平面交）。** 在检测点 `p_i` 测得示向度 `θ_i`，真实方位落在 `[θ_i − ε, θ_i + ε]`。
该观测对应的楔形 `W_i` 是两条边界射线所定义的两个半平面之交：

- 下边界射线方向 `θ_i − ε`，保留其**左侧**（逆时针一侧）半平面；
- 上边界射线方向 `θ_i + ε`，保留其**右侧**半平面。

对方向 `φ` 的射线，其左侧法向为 `(−sin φ, cos φ)`，半平面写作 `a·x + b·y ≤ c`。多个观测的定位
区域为各楔形之交

```
P = ⋂_i W_i = ⋂_i ( H_i^low ∩ H_i^up ).
```

因半平面之交是凸集，`P` 必为**凸多边形**（或退化为线段 / 单点 / 空集）。

**含真值性（性质 P1，验证 R1.3）。** 只要每条示向度误差落在 `[−ε, +ε]` 内，真实源方位就落在每
个楔形 `W_i` 的角域内，故真实源位置落在所有楔形之交 `P` 内——即**定位区域必包含真实源**。这为
"用 `P` 的质心作位置估计、用 `D` 度量不确定度"提供了理论保证。

**输入契约与退化（R1.1/R1.2/R1.4）。**

- 交会定位至少需要 `N ≥ 2` 个检测点；`N < 2` 时 `localization_region` 显式抛
  `ValueError`（拒绝输入，不产生定位区域）。
- 各楔形之交为空、或其面积不超过 `MIN_REGION_AREA = 1e-9` m²（观测互相矛盾或退化）时，返回
  **空定位区域**并附"交会为空"指示（`empty=True, reason="交会为空"`）。

## 1.3 定位区域直径算法

**关键引理（凸集直径在极点取到）。** 凸多边形上任意两点的最大距离必在**顶点对**上取得。

*证明。* 距离函数 `f(u, v) = ‖u − v‖` 关于每个变量都是凸函数；在凸紧集上，凸函数的最大值必在
极点（顶点）取得。固定 `u` 令 `v` 遍历 `P`，最大值在 `P` 的某顶点取到；再令 `u` 遍历，最大值同
样在顶点取到。故 `D(P) = max_{u,v ∈ vertices(P)} ‖u − v‖`。∎

因此只需枚举顶点对，顶点数很小（不超过观测数的常数倍），`O(m²)` 即可。

**算法（与 `geometry.py` 实现一致）。**

```
ALGORITHM RegionDiameterAndCover(bearings):
  # ---- 楔形交会得到凸定位区域 ----
  IF len(bearings) < 2:  RAISE ValueError            # R1.2
  poly ← BigSquare(bound = 4R)                       # R = ARENA_RADIUS = 1800 m
  FOR each b IN bearings:
      FOR each plane IN wedge_half_planes(b, ε=1°):  # 每观测 2 个半平面
          poly ← clip_polygon(poly, plane)           # Sutherland–Hodgman 裁剪
          IF poly is empty:  RETURN (交会为空)         # R1.4
  IF area(poly) ≤ 1e-9:  RETURN (交会为空)             # R1.4 退化

  # ---- 区域直径：顶点对最大距离 ----
  D ← −1;  (A, B) ← (poly[0], poly[0])
  FOR i IN 0..m−1:
      FOR j IN i+1..m−1:                             # 索引升序，配合严格 >
          d ← ‖poly[i] − poly[j]‖
          IF d > D:  D, (A, B) ← d, (poly[i], poly[j])
  # 存在并列最大顶点对时，因"严格大于"仅在更大值时替换，
  # 故确定性返回按 (i, j) 升序的首个顶点对（R1.5）。

  # ---- 外接圆覆盖判定 ----
  M ← (A + B) / 2 ;  r ← D / 2
  worst ← max_{v ∈ poly} ‖v − M‖
  margin ← r − worst                                 # R1.8
  covers ← (worst ≤ r + 1e-7)                        # ⟺ margin ≥ −1e-7 (R1.7)
  RETURN D, (A, B), covers, margin
```

**直径的确定性（R1.5，性质 P2）。** 当多个顶点对同时取得最大距离时，外层 `i`、内层 `j` 均按
索引升序遍历，且仅当出现**严格更大**距离时才替换当前最优，故最先达到最大值的顶点对被保留——
返回结果确定、可复现。

**退化直径（R1.6）。** 若非空区域退化为**单点**（所有顶点两两距离 `≤ 1e-7` m），返回 `D = 0`；
退化为**线段**（顶点共线），返回 `D` = 两端点欧氏距离。两种退化均标记为"覆盖"（见下）。

## 1.4 外接圆覆盖判据与覆盖裕度

记以直径端点 `A、B` 为直径的圆 `C`：圆心 `M = (A + B) / 2`、半径 `r = D/2`。定义**覆盖裕度**

```
margin = D/2 − max_{v ∈ vertices(P)} ‖v − M‖  （单位：米）,
```

并规定判据（R1.7/R1.8）

```
covers ⟺ max_{v} ‖v − M‖ ≤ D/2 + 1e-7 ⟺ margin ≥ −1e-7.
```

**关于 `margin` 符号的一个结构性观察。** 直径端点 `A、B` 到中点 `M` 的距离**恒等于** `D/2 = r`。
因此 `max_v ‖v − M‖ ≥ D/2`，从而 **`margin ≤ 0` 恒成立**：

- `margin ≈ 0`（最远顶点即直径端点 `A/B`）⟺ 直径圆**覆盖**整个区域；
- `margin < 0`（存在**非端点**顶点落在圆外）⟺ 直径圆**不覆盖**。

`margin` 的绝对值即"最远顶点超出圆的距离"，直接量化了直径圆作为外接圆的不足程度。工程上定位
区域常呈狭长四边形（两条近平行窄楔相交，见 §1.6 覆盖例），此时最远顶点恰为直径端点、`margin ≈ 0`
覆盖成立；但**不能默认**，必须按判据逐案例检验。

退化区域（R1.6）：单点 `D = 0` 判"覆盖"、`margin = 0`；线段所有顶点落在以直径为直径的圆上（即
在区间内），`max‖v−M‖ ≤ D/2`，同样判"覆盖"。

## 1.5 结论与反例：直径圆不一定覆盖定位区域

**结论。** 以区域直径为直径的圆**不一定**覆盖整个定位区域。

**反例族（正三角形）。** 取边长为 `L` 的正三角形作为定位区域的顶点集。三边等长，故直径
`D = L`（任两顶点距离相等，取其一为直径）。以任一边为直径的圆半径为 `L/2`、圆心在该边中点 `M`；
而**第三个顶点到 `M` 的距离**为三角形的高

```
h = L · (√3 / 2) = 0.8660254… · L  >  L/2,
```

即第三个顶点落在直径圆**之外**。此时

```
margin = D/2 − h = L/2 − (√3/2)L = (1 − √3)/2 · L = −0.3660254… · L  <  0,
```

判定为**不覆盖**。这正是本方案 `src/b_q1_figures.py` 生成的
[图 1-2 反例图](../figures/b_q1_covering_counterexample.png)：`L = 100` m 时 `D = 100.00` m、
`r = 50.00` m、最远顶点距 `M` 为 `86.60` m、`margin = −36.60` m，直径圆不覆盖。

**为什么反例来自锐角而非钝角三角形（一个易错点，见 `src/b_q1_redteam_fix.py`）。** 一个直觉误
区是"钝角三角形以最长边为直径的圆盖不住钝角顶点"。事实恰相反：

- **钝角 / 直角三角形**：最大角 `≥ 90°`，其**最小外接圆恰为**以最长边为直径的圆，第三顶点落在
  圆内（钝角）或圆上（直角，临界仍覆盖）——直径圆**能**覆盖，`R/(D/2) = 1`；
- **锐角三角形**：三个角都 `< 90°`，最小外接圆由三点共圆决定，半径 `R = abc/(4K) > D/2`（`K`
  为面积），直径圆**不能**覆盖——**这才是反例的来源**；
- **极值**：正三角形取到 `R/(D/2) = 2/√3 = 1.15470`，即下述 Jung 上界。

推广到一般凸多边形：若定位区域的顶点集中存在一个**锐角三角形**，则该三点的外接圆半径
`> D/2`，以直径为直径的圆无法覆盖整个区域。`src/b_q1_counterexample.py` 用四检测点（真实源
`(600, 500)`、示向度取真值）交会出一个凸四边形，其四个顶点三角形均为锐角三角形，最小外接圆半径
`R > D/2`，直径圆不覆盖，`mpmath` 60 位精度复核 `margin < 0`，与本判据数值一致。

## 1.6 平面最紧上界：Jung 定理

**Jung 定理（平面情形）。** 平面上任一直径为 `D` 的有界点集，其**最小外接圆半径** `r*` 满足

```
r* ≤ D / √3 ≈ 0.5774 · D,
```

且上界在**正三角形**处取到（`r* = D/√3`）。

**意义。** "直径圆"的半径为 `D/2 = 0.5·D`，而最坏情形下需要 `D/√3 ≈ 0.577·D` 才能覆盖；二者之
比恰为 `(D/√3)/(D/2) = 2/√3 = 1.1547`。因此：

- 直径圆半径 `D/2` 在最坏情形下**不足**以覆盖定位区域（缺口比例约 `15.5%`）；
- 覆盖当且仅当最远顶点到 `M` 的距离 `≤ D/2`（即上文判据）；
- 若想用**单个圆**保证覆盖任意直径为 `D` 的定位区域，应取半径 `D/√3` 的最小外接圆，而非直径圆。

Jung 上界给出了"直径圆够不够"这一问题的**紧致理论边界**，正三角形反例正好落在该边界上，从而
既证明了"不一定覆盖"，又刻画了最坏程度。

## 1.7 覆盖成立的典型情形（配图）

尽管一般不成立，实际交会定位中定位区域常呈**狭长四边形**：两条近似平行的窄楔相交，区域在"直
径方向"很长、"横向"很窄。此时最远顶点恰为直径端点，`margin ≈ 0`，直径圆覆盖成立。

[图 1-1 覆盖例](../figures/b_q1_localization_diameter_covered.png)由两条示向度楔形（估计源
`≈(500, 300)`、两检测点使交会角落在良态区间）交会得到一个凸四边形定位区域：`D = 76.62` m、
`r = D/2 = 38.31` m、`max‖v−M‖ = 38.31` m、`margin ≈ 0.00` m，直径圆恰好覆盖整个区域。图中同时
标出定位多边形 `P`、直径 `AB`、外接圆与中点 `M`，以及决定覆盖与否的"最远顶点"。

## 1.8 小结

| 对象 | 结果 |
| --- | --- |
| 定位区域 `P` | 各 ±1° 示向度楔形（半平面交）之交，凸多边形；含真值（P1，R1.3） |
| 区域直径 `D` | 顶点对最大距离，`O(m²)` 枚举，确定性返回（P2，R1.5） |
| 覆盖判据 | `covers ⟺ max‖v−M‖ ≤ D/2 + 1e-7 ⟺ margin ≥ −1e-7`（P3，R1.7/R1.8） |
| 覆盖裕度 | `margin = D/2 − max‖v−M‖ ≤ 0`；`≈0` 覆盖、`<0` 不覆盖 |
| 结论 | 直径圆**不一定**覆盖；正三角形反例第三顶点距中点 `0.866L > L/2` |
| 平面上界 | Jung：`r* ≤ D/√3 ≈ 0.577D`，正三角形取到（最紧） |
