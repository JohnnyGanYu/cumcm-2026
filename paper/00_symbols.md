# 符号说明

| 符号 | 含义 | 单位 |
|---|---|---|
| $R_{\text{area}}$ | 目标区域半径，$1800$ | m |
| $\varepsilon$ | 示向度误差界，$1^\circ$ | 度 |
| $r_{\text{clear}}$ | 清除半径，$20$ | m |
| $\rho$ | 干扰源有效接收半径，取值于 $[1000,1500]$ | m |
| $\rho_{\min}$ | 有效接收半径下限，$1000$（稳健设计取值） | m |
| $v$ | 机器狗移动速度，$5$ | m/s |
| $t_{\text{m}}$ | 单次检测耗时，$5$ | s |
| $t_{\text{sw}}$ | 频道切换耗时，$1$ | s |
| $t_{\text{c}}^{+}$ / $t_{\text{c}}^{-}$ | 清除成功 / 失败耗时，$5$ / $3$ | s |
| $T_{\max}$ | 虚拟世界总时长上限，$360\,000$ | s |
| $T_{\text{wall}}$ | 程序真实运行时间上限，$1200$ | s |
| $S_i=(x_i,y_i)$ | 第 $i$ 个检测点坐标 | m |
| $\tilde\theta_i$ | 在 $S_i$ 处测得的示向度读数 | 度 |
| $\theta_i$ | 真实方位角 | 度 |
| $W_i$ | $S_i$ 处示向度确定的扇形约束域 | — |
| $\Omega$ | 定位区域，$\Omega=\bigcap_i W_i$ | — |
| $d$ | 定位区域直径 | m |
| $R$ | 定位区域的最小外接圆半径 | m |
| $\gamma$ | 两条示向度的交会夹角 | 度 |
| $d_1,d_2$ | 干扰源到第一、第二检测点的距离 | m |
| $N$ | 干扰源总数，$10\le N\le16$ | 个 |
| $N_c$ | 被清除干扰源个数 | 个 |
| $\bar t$ | 平均定位清除时间，$\bar t=T_{\text{total}}/N_c$ | s |
