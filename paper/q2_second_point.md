## 2.1 问题重述

测向机在检测点 `p_1` 对某频道检测，返回带 ±1° 误差的示向度 `θ_1`（正东为 0°、逆时针为正）。
单条示向度只能把干扰源约束在一条 ±ε（`ε = 1°`）的窄楔内，沿视线方向的距离完全未知，无法
定位。要交会定位，必须选取**第二检测点** `p_2` 并在此获得第二条示向度 `θ_2`，两条示向线相交
把源约束到一个有界的凸定位区域。问题二要求：给出第二检测点 `p_2` 的**选择策略**与其**候选
区域**，使交会定位良态（定位区域小、且不因走出接收半径而失败）。

本章结论：第二检测点应"**沿示向度方向前进 + 叠加小角度偏移**"生成，取偏移角集合
`δ ∈ {32°, 16°, 0°}`、前进长度 `L = 380 m`，按 `δ` 由大到小逐级退让；其候选区域是以
`θ_1 ± 32°` 为角边界的前向楔形内、交会角 `α ∈ [60°, 120°]`、`d_2 ≤ 1000 m` 且
`‖p_2‖ ≤ 1800 m` 的**环状扇形带**。**关键教训：绝不可做大幅横向平移取 `p_2`**——横向平移
极易走出源的有效接收半径而返回 `no_signal`，离线实测把清除率从 81% 打到 45%。

## 2.2 交会定位的一阶误差传播

两条示向线（近似）交于源 `s`，其**交会角** `α` 为两条视线 `s→p_1`、`s→p_2` 的夹角
（实现见 `geometry.crossing_angle_deg`，返回 `[0°, 180°]`）。设两检测点到源的距离分别为
`d_1`、`d_2`，示向度误差绝对上界 `ε = 1°`。每条示向线的横向不确定度约为 `d_i·ε`（弧长近似），
两条 ±ε 窄楔各自宽约 `w_i = 2·d_i·ε`，其相交所得平行四边形定位区域的关键度量为：

- **沿平分线方向的展宽**（一阶传播）：

  ```
  展宽 ≈ (d_1 + d_2)·ε / sin α
  ```

  该式表明：定位精度与 `1/sin α` 成正比，`sin α` 越大越好，`α = 90°` 时误差放大最小。

- **定位区域直径**（平行四边形长对角线）：

  ```
  D ≈ sqrt(w_1² + w_2² + 2·w_1·w_2·|cos α|) / sin α,   w_i = 2·d_i·ε
  ```

由 `1/sin α` 的形态可直接读出三条约束（对应 §2.3 的三个约束条件）：

1. **交会角约束**。`sin α` 在 `α → 0°`（近共线）或 `α → 180°`（近反向共线）时趋于 0，误差被
   无限放大。为把放大倍数封顶，取良态带 `α ∈ [60°, 120°]`（等价 `sin α ≥ √3/2 ≈ 0.8660`）。
   在此带内，误差放大 `1/sin α ≤ 2/√3 ≈ 1.1547`，即**相对最优（`α = 90°`）至多恶化约
   15.5%**。这正是 `[60°, 120°]` 这一区间的量化依据（配图 `b_q2_gamma_effect.png` 第三子图）。

2. **误差随距离收缩**。横向误差 `≈ d_2·ε` 随 `d_2` 单调增大，故 `p_2` 越靠近源越好——这与
   Q3/Q4 "沿示向度逐步逼近、误差随距离单调收缩"的归航策略一致（见 §2.6 与性质 P8）。

3. **接收半径约束**。见 §2.3。

> **数值示例（脚本实测，`ε = 1°`）**：距离 `r` 处示向度误差引起的横向定位误差
> `e(r) = r·tan(1°)`（`strategy.lateral_error_at`）给出 `e(100 m) = 1.75 m`、
> `e(500 m) = 8.73 m`、`e(1000 m) = 17.46 m`。逼近到 100 m 内，横向误差已压到米级。

## 2.3 三个约束条件

**(a) 交会角约束（几何良态）。** `α ∈ [60°, 120°]`（边界值 60°、120° 均判为有效，实现带
`1e-7` 度容差）。`α < 60°` 或 `α > 120°` 的候选视为**几何病态**（近共线，误差放大 > 1.155 倍
且迅速发散），从有效候选集中剔除，绝不作为选定的第二检测点（R2.2/R2.3）。

**(b) 接收半径约束。** 源的有效接收半径 `R_s ∈ [1000, 1500] m` 未知。为**保守保证** `p_2` 处
仍能收到该源信号（否则 `p_2` 处 `no_signal`，交会失败），要求第二检测点到源的估计距离
`d_2 ≤ 1000 m`（取接收半径的保证下限，边界含）。

**(c) 越界约束。** `p_2` 必须留在目标圆域内：`‖p_2‖ ≤ 1800 m`（`ARENA_RADIUS`，边界含）。

一个候选**有效**当且仅当同时满足 (a)(b)(c)（实现见 `classify_second_point_candidates`）。

## 2.4 候选生成策略：沿示向度前进 + 小角度偏移

源位于 `p_1` 沿 `θ_1` 方向的射线附近（距离 `d_1` 未知但 `≤ R_s`）。要使从 `p_2` 观测到的交会角
落入 `[60°, 120°]`，`p_2` 应相对示向线**偏转**一个角度后前进。工程实现取一个稳健的固定偏移角
集合并沿示向度方向前进固定长度，生成候选点集（设计 §3.2/§4.4）：

```
p_2 ∈ { p_1 + L·(cos(θ_1 + s·δ), sin(θ_1 + s·δ)) : δ ∈ {32°, 16°, 0°}, s ∈ {+1, −1}, L = 380 m }
```

其中前进长度 `L = 380 m`（`dogleg_length_m`，容差 ±1 m），偏移角 `δ` 按由大到小取自
`{32°, 16°, 0°}`（`dogleg_offset_deg = 32°` 为上界）。约定：

- 候选序列按 `δ` **降序**排列；对每个 `δ > 0` 生成 `s = +1` 与 `s = −1` 一对候选（先 `+` 后
  `−`）；`δ = 0°` 只生成一个沿示向度直行的候选。此顺序对应"**先大偏移博取良态交会角、失败
  再退让、最终退化为沿示向度直行**"的遍历策略（`geometry.second_point_candidates`，R2.1）。
- 生成方式仅为"沿 `θ_1` 前进 + `|δ| ≤ 32°` 小角度偏移"。因 `|δ| ≤ 32° < 90°`，前进分量
  `L·cos δ > 0` 恒为正，故**绝不产生偏移 `|δ| > 32°` 或无前进分量（`L·cos δ ≤ 0`）的纯横向
  平移 / 反向候选**（R2.4）。生成侧对 `|δ| > 32°` 直接抛错拒绝。

**退让与失败语义（R2.5/R2.6，`select_second_point`）。** 按上述顺序逐个考察候选：若候选无效
（交会角病态 / `d_2 > 1000` / `‖p_2‖ > 1800`）或该点检测返回 `no_signal`，则退让到下一个更小
的 `δ`，最终退化为 `δ = 0°` 沿示向度直行的安全兜底。IF 所有候选（含 `δ = 0°`）均无效或均
`no_signal`，THEN 返回显式的"第二检测点不可行"失败结果（附失败原因），**不选定任何越界或
病态候选**，并保持 `p_1` 处已获数据不变。

> **数值示例（脚本实测，`p_1 = (0,0)`、`θ_1 = 30°`、对源距离估计 `d_1 = 350 m`、`L = 380 m`）**：
>
> | 偏移 `δ` | `p_2` | 交会角 `α` | `d_2` | 是否在候选区域 |
> |---|---|---|---|---|
> | `+32°` | `(178.4, 335.5)` | `82.2°` | `203.3 m` | 是（有效） |
> | `−32°` | `(379.8, −13.3)` | `82.2°` | `203.3 m` | 是（有效） |
> | `+16°` | `(264.0, 273.3)` | `98.3°` | `105.9 m` | 是（有效） |
> | `−16°` | `(368.7, 91.9)` | `98.3°` | `105.9 m` | 是（有效） |
> | `0°`  | `(329.1, 190.0)` | `180.0°` | `30.0 m` | 否（共线病态） |
>
> 可见 `δ = 32°`/`16°` 偏移给出良态交会角（82°、98° ∈ [60,120]），而 `δ = 0°` 沿示向度直行时
> `p_1`、`p_2`、源三点共线、`α = 180°`，交会退化——`δ = 0°` 仅作退无可退时的安全兜底，其价值
> 是"继续沿视线单调靠近源、增强信号"，而非当场完成交会。配图 `b_q2_candidate_region.png` 完整
> 叠加了这一候选序列（有效候选用蓝色圆点、被剔除的 `δ = 0°` 用灰色叉号标出）。

## 2.5 候选区域的界定

综合 §2.3 三约束与 §2.4 的前向楔形，第二检测点的**候选区域**界定为
（`geometry.second_point_candidate_region` / `in_second_point_region`，R2.7）：

```
R(p_1, θ_1) = { p_2 :
      (1) p_1→p_2 的方位与 θ_1 的最小角差 ≤ 32°   （θ_1 ± 32° 前向楔形，隐含前进分量为正）
  AND (2) α(source; p_1, p_2) ∈ [60°, 120°]        （交会角良态）
  AND (3) d_2 = ‖p_2 − source‖ ≤ 1000 m            （接收半径保证下限）
  AND (4) ‖p_2‖ ≤ 1800 m }                          （不越界）
```

它是一条以 `p_1` 为顶点、`θ_1 ± 32°` 张开的前向楔形内、被交会角带与接收半径带切出的
**环状扇形带**。区域内 `α ∉ [60°, 120°]` 或 `‖p_2‖ > 1800 m` 的点被明确排除。边界一律判为
"在区域内"（含），数值容差沿用交会角 `1e-7°`、距离 `1e-7 m`。

**配图 `b_q2_candidate_region.png`（两情形）。** 左：`p_1` 在区域中心（`θ_1 = 30°`）；右：`p_1`
靠近边界（`θ_1 = 205°`）。图中浅蓝为 `θ_1 ± 32°` 前向楔形、红色散点为逐点调用
`in_second_point_region` 判定为真的候选区域、绿色虚线为实测示向度 `θ_1 ± 1°`，蓝色圆点/灰色
叉号为 `second_point_candidates` 实际生成的 `{32,16,0}°/380 m` 候选序列及其有效性，橙色三角为
按当前估计的源位置。两情形均可见：候选区域关于示向线对称地分布在其两侧的前向扇带内，且不含
示向线正上（近反向共线）区域——这正是"必须偏转、不可纯直行、更不可横向平移"的几何来源。

## 2.6 关键教训：不可大幅横向平移

> **写入论文的核心教训**：取第二检测点**绝不可做大幅横向平移**（即偏移 `|δ|` 过大、甚至
> 垂直于示向度平移）。

原因有二，二者叠加解释了实测的清除率崩塌：

1. **走出接收半径 → `no_signal`。** 横向平移在增大交会角的同时急剧增大 `d_2`。当 `d_2` 超过
   源的有效接收半径下限（保守 1000 m）时，`p_2` 处收不到该源信号，第二条示向度无从获得，交会
   直接失败。源辐射存在扇区限制（尤其定向源）时，横向平移还可能移出辐射扇区，同样 `no_signal`。

2. **偏离"沿视线单调靠近"的安全路径。** 大幅横向平移使机器狗远离源、信号变弱，且一旦
   `no_signal` 就失去可继续逼近的方向基准，只能重新普扫，浪费大量移动与检测预算。

设计取 `|δ| ≤ 32°` 的小角度偏移正是这两难的折中：偏移足够大以在 `d_1` 落在合适量程时博取良态
交会角（见 §2.4 实测 `δ = 32°` 给出 `α = 82°`），又足够小以保证前进分量为正、`d_2` 受控、
不轻易走出接收半径；一旦更大偏移失败，即按序退让到更小偏移，最终退化为沿示向度直行——**始终
不脱离"沿视线单调靠近源"的安全路径**。

> **离线实测代价**：把"沿示向度前进 + 小角度偏移"替换为"大幅横向平移"取 `p_2` 后，清除率从
> **81% 跌到 45%**（相同案例族、相同预算）。这一 36 个百分点的落差是本策略"沿示向度前进 +
> 小角度偏移、逐级退让"的直接实证依据，也是 Q3/Q4 归航段沿示向度逐步逼近（`approach_fraction`
> 前进 + 小 `lateral_fraction` 横向偏移）而非横向平移的原因。

## 2.7 逼近误差的单调性（性质 P8）

量化"越靠近源越准"的必要性：距离 `r`（米）处示向度误差引起的横向定位误差为

```
e(r) = r · tan(1°)          （strategy.lateral_error_at, ε = 1° 为示向度误差绝对上界）
```

因 `tan(1°) > 0` 为正常数，`e(r)` 关于 `r` **严格单调递增**：对任意 `r_2 > r_1 ≥ 0` 有
`e(r_2) > e(r_1)`（正确性性质 P8，验证 R2.8）。故每次沿示向度逼近使 `r` 减小，横向误差随之
单调收缩——这是"沿示向度逐步逼近"能持续提升定位精度的根据。实测 `e(1000) = 17.46 m`、
`e(500) = 8.73 m`、`e(100) = 1.75 m`。
