# B 题离线演练环境

在**没有官方模拟器**的机器上无限次演练机器狗策略。官方模拟器是最终判据；
本目录任何行为与官方不一致处，以官方实测为准。

## 策略要点与实测教训

1. **必须逐步逼近，不能远距离一次定位。** 示向度误差 ±1°，在 r 处横向误差约
   0.0175 r：1500 m 处约 26 m，超过 20 m 清除半径；100 m 处仅 1.7 m。策略"边靠近
   边重测"，让几何误差随距离自然收缩。

2. **dog-leg 必须沿示向度方向前进，不能横向平移。** 横向平移会走出有效接收半径，
   实测导致远距离源大量丢失（清除率一度只有 45%）。沿示向度前进单调靠近目标，
   信号只会更强，用小角度偏移换交会角。

3. **环形补扫是主路径，不是兜底。** 实测约 51% 的干扰源站在原点收不到信号。
   环参数按"最坏覆盖间隙 < 接收半径下限 1000 m"直接选：原点 + 半径 1250 m 的 12
   个站位，最坏间隙 670 m，13 个站位即可覆盖全域；双环 23 站位成本高 77% 而收益有限。

4. **检测预算要分"搜索"和"归航"两段。** 定向源在找到信号前可能烧掉几十次检测。
   若用同一个预算，会出现"刚拿到示向度就被判预算耗尽而放弃"（实测 seed 3004 ch20：
   已测得距真值 413 m 的示向度、候选压缩到 2 个格点，却被判死）。拿到首个示向度后
   归航额度重新起算。

5. **定向源靠推理 + 盲清除，不靠加密站位。** 盲扫有天花板：37 个站位仅 98.7% 可见率
   且成本翻倍。改用两步：
   - "检测无信号"是约束——距离 ≤ 1000 m 时无信号即意味着观测点在辐射扇区之外，
     据此在 `(位置, 朝向)` 离散网格上排除矛盾状态（实测 10 次沉默观测把 8508 个
     候选压到 2166，真值始终保留）；
   - `/clear` 判定只看距离、与辐射方向无关，因此对候选格点直接盲清除。
     漏失的定向源全部"物理可解"（可见扇区一直延伸到源身边 4-10 m，但仅占目标区域
     0.1%-19%），盲清除把全清局数从 11/20 提到 17/20。

6. **`_probe_candidates` 不能只用候选源位置当观测点。** 定向源朝区域外辐射时，
   能看见它的点位于源的外侧（沿其朝向前方），未必是候选源位置本身。

7. **归航失败的频道要按"几何"复活，不能按"时间"等。** 评分指标
   `mean_clear_time_s` 的 **55%** 来自最慢 3 个源，而这些源的特征是"第一次归航
   失败"（头部源 `fails=0`，尾部源 `fails=1`）。实测有源在 t=119 s 就拿到示向度，
   却到 t=9398 s 才被清除：失败后要等 **p50=6809 s**（整环走完才调用
   `_revive_exhausted`），而第二次归航只花 **p50=248 s** 就成功。浪费的是等待。
   改为路过其估计位置 900 m 内即刻重试（`_revive_nearby`），98 局 4 档配对实测
   Q3 −0.6% / 5定向 −4.1% / 10定向 −5.3% / 16定向 −6.1%，清除率与漏失数不变。

## 优化的账：钱在哪，以及 5 个被证伪的方案

时间去向实测（官方练习日志 + 本地仿真一致）：**移动 81%、检测 15%、清除 0.5%**。
所以优化必须针对移动与调度，估计器不是瓶颈（见下节）。理论下界：若每个源在
首次拿到示向度后 248 s 内清除，`mean_clear_time_s` 从 3807 s 降到 2414 s（−37%）。

被实测否决的方案，全部保留供论文写"试过但无效"：

| 方案 | 结果 | 失败原因 |
|---|---|---|
| retry_soon（原地立即重试） | +6.8 s | 同一失败几何必然再失败 |
| ray_earlier（提前射线盲扫） | +19.6 s | 治症状不治因 |
| clip / shrink（越界候选裁剪） | +60.5 s，6/8 更差 | 边界处交会角差，观测质量低 |
| eager（发现即归航到底） | +74.1 s，7/8 更差 | 造成专程往返，与 `home_batch` 结论同源 |
| **survey_first（先勘察后统一清除）** | Q4 −18%，但 **Q3 +33%**、各档掉 1–5 个源 | 见下 |

`survey_first` 是最值得记录的一次证伪：12 局小样本上是 −249 s（−18.9%）且多清
1 个源，看起来是突破；4 档全量验证（98 局）却推翻它——**Q3 恶化 32.7%（23/24
更差）**，且每档都掉源。原因是严格两阶段拆掉了 `_probe_ring ↔ _home_all` 的
交替往返，而那个往返正是"接收半径贴近下限 1000 m"的源反复获得新交会几何的机制；
Q3 本无尾部问题（meanT 458 s），两阶段只是纯增加勘察前置成本。

**教训：小样本单场景的强结果不可信，任何改动必须跨全部难度档（Q3/5/10/16 定向）
配对验证，并同时看清除率与耗时两个轴。**

## 单点估计 vs 完整后验：已量化否决

有界 ±1° 误差下，楔形交集**就是**精确后验、面积质心**就是**后验均值，因此粒子/
网格滤波提供不了新信息。110 对配对局（含 16/16 全定向）实测：清除率 100% vs
100%，虚拟时间仅省 0.94%，而漏失源 3 → 5（更差）。清除失败发生在后验本身过大时
（失败样本直径 p50=283 m），且现有兜底已把 14/14 个受影响频道全部清除成功。
剩余漏失是**可观测性**问题（可见区仅占目标区域 0.03%–0.22%，两臂完全相同），
与估计器无关。副产品：后验直径预测清除失败 AUC=0.9907，可做 3 行不确定度门禁。

细节见 `src/b_belief_{eval,replay,endtoend,ablation,live}.py` 与
`src/b_{move_audit,tail_diag,exitpath,nearby_revive,survey_first}.py`。

## 与官方模拟器对接

`client.py` 直接指向 `http://127.0.0.1:2026` 即可用于官方模拟器（同机运行，
接口只监听回环）。正式测试前务必：

- 用演练模式（不限次数）跑通全流程，确认协议字段、超时和异常分支；
- 检查 `/enter` 返回的 `remaining_real_duration_s`，不要假定固定 1200 s；
- 自行保存完整指令与响应序列（`client.dump_log`），模拟器不提供该功能；
- 问题 3/4 各只有 3 次正式测试机会，且 9/13 17:30 之后不能开新测试。

## 本仿真器所做的假设（写入论文须声明）

题面与附件未明确、由本实现设定的部分：

1. 示向度误差在 [-1, 1] 度内，按检测点位置确定性生成（同一地点重复检测读数一致）；
2. 定向源辐射扇区为朝向两侧各 90 度、含边界；
3. 案例生成中干扰源位置在目标区域内均匀分布，有效接收半径在 [1000, 1500] m 内均匀分布；
4. 清除判定只看平面距离 ≤ 20 m，与辐射方向和频道切换无关。
